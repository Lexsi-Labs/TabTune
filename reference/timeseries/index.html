    API: Time Series¶

    The public classes and functions of tabtune.TimeSeries and tabtune.bridge, rendered from their docstrings. The guides are under Time Series.

    Pipeline¶

    tabtune.TimeSeries.pipeline.TimeSeriesPipeline ¶

    Fit, forecast with and evaluate a time series foundation model.

    __init__(model_name: str, task_type: str = 'forecasting', tuning_strategy: str = 'inference', tuning_params: dict | None = None, model_params: dict | None = None, forecast_params: dict | None = None, *, task_params: dict | None = None, cache: Any = None, envelope_mode: str = 'warn', license_mode: str = 'research', validate: bool = True) -> None ¶

    Build a pipeline around a time series foundation model.

    Parameters:

    Name Type Description Default
    model_name str

    Model name or alias. See :func:tabtune.registry.list_time_series_models; register your own with :func:tabtune.registry.register_time_series_model.

    		 required
    task_type str

    "forecasting" (default), "anomaly_detection", "imputation" or "embedding". :meth:predict returns a :class:ForecastResult, :class:AnomalyResult, :class:ImputationResult or :class:EmbeddingResult.

    		 'forecasting'
    tuning_strategy str

    "inference" (zero-shot), "finetune" (all weights) or "peft" (LoRA adapters), for models whose spec declares them.

    		 'inference'
    tuning_params dict | None

    For zero-shot inference only device and seed apply. Fine-tuning also reads epochs and steps_per_epoch (one step is one batch of sampled windows; default 50 per epoch), learning_rate, batch_size, early_stopping with early_stopping_patience (in epochs), validation_split (any value above 0 holds out the last prediction_length steps of every series), gradient_clip_norm (default 1.0) and, for "peft", peft_config (r, lora_alpha, lora_dropout, target_modules).

    		 None
    model_params dict | None

    checkpoint selects the weights: a validated checkpoint id (defaults to the spec's default_checkpoint) or a local checkpoint directory. device selects the device when tuning_params does not. Other keys are forwarded to the model's adapter.

    		 None
    forecast_params dict | None

    Validated against :class:~tabtune.config.ForecastConfig. prediction_length is required for forecasting; for anomaly detection it is the number of steps forecast from each origin (default 1).

    		 None
    task_params dict | None

    Task options. Anomaly detection: method ("forecast_error", "interval" or "likelihood"), stride, min_context, coverage, alpha, threshold ("conformal", "contamination" or a number), contamination and reference_fraction. Imputation: method ("bidirectional" or "forecast") and min_context.

    		 None
    cache Any

    Result cache: 'memory', 'disk', None or a :class:~tabtune.caching.PredictionCache.

    		 None
    envelope_mode str

    How to treat requests beyond the model's documented limits: 'error', 'warn' (default) or 'ignore'.

    		 'warn'
    license_mode str

    'research' (default), 'commercial' to fail fast on weights that forbid commercial use, or 'ignore'.

    		 'research'
    validate bool

    Check the weight license and restrict checkpoint to the validated list (local directories are always allowed). The model, task and strategy are checked regardless, because the pipeline cannot run anything else.

    		 True

    Raises:

    Type Description
    ModelNotFoundError

    Unknown model name.
    UnsupportedTaskError

    The model does not implement task_type.
    UnsupportedStrategyError

    The model does not support tuning_strategy.
    LicenseError

    license_mode='commercial' and the weights forbid it.
    ConfigError

    Invalid forecast_params, tuning_params, task_params, checkpoint, envelope_mode or license_mode.

    fit(df: pd.DataFrame, schema: TimeSeriesSchema, *, future_df: pd.DataFrame | None = None) -> TimeSeriesPipeline ¶

    Validate the history, load the model and, for fine-tuning, train it.

    For zero-shot inference no training happens: fit validates and stores the history and loads the weights. With "finetune" or "peft" the model is then trained on windows sampled from the history; :attr:training_report_ records the run.

    Parameters:

    Name Type Description Default
    df DataFrame

    Long-format history, one row per (item, timestamp).

    		 required
    schema TimeSeriesSchema

    Names the target, timestamp, item and covariate columns.

    		 required
    future_df DataFrame | None

    Values of the schema's known_covariates over the horizon that follows this history. Only needed when the schema names any; :meth:predict can supply a different one.

    		 None

    Returns:

    Type Description
    TimeSeriesPipeline

    self.

    Raises:

    Type Description
    ValueError

    If df does not satisfy schema.
    ConfigError

    If the schema uses a feature the model does not support, such as covariates or several targets.
    UnsupportedStrategyError

    If the model's adapter cannot be trained.
    EnvelopeError

    If the horizon exceeds the model's documented limit and envelope_mode='error'.
    ImportError

    If the model's adapter or its backend is not installed.

    predict(df: pd.DataFrame | None = None, *, future_df: pd.DataFrame | None = None) -> ForecastResult | AnomalyResult | ImputationResult | EmbeddingResult ¶

    Run the pipeline's task on the fitted history or on df.

    Forecasting returns prediction_length steps past the end of each series; anomaly detection scores every observation after a warm-up; imputation returns the history with its gaps filled; embedding returns one vector per series.

    Parameters:

    Name Type Description Default
    df DataFrame | None

    History in the fitted schema. None uses the history given to :meth:fit. Passing a frame runs the task on new origins or new items without refitting.

    		 None
    future_df DataFrame | None

    Values of the schema's known_covariates over the horizon (forecasting only). None reuses the ones given to :meth:fit, which only match when the forecast origins have not moved.

    		 None

    Returns:

    Type Description
    ForecastResult | AnomalyResult | ImputationResult | EmbeddingResult

    An immutable result, safe to share when cached.

    Raises:

    Type Description
    RuntimeError

    If called before :meth:fit.
    ValueError

    If a series has no observed value within the model's context window.
    ConfigError

    If the schema names known covariates and no values for the horizon are available.

    calibrate(df: pd.DataFrame | None = None, *, method: str | None = None, windows: int = 5, step: int | None = None, output_format: str = 'rich') -> TimeSeriesPipeline ¶

    Calibrate the forecast quantiles with split conformal prediction.

    Forecasts are made from windows rolling origins at the end of the history (or of df), compared with what followed, and the per-horizon-step errors set how much each quantile moves. Later :meth:predict calls return the calibrated quantiles; the point forecast is unchanged. Fitting again removes the calibration.

    Use a history the model was not fine-tuned on, or the calibration will be optimistic.

    Parameters:

    Name Type Description Default
    df DataFrame | None

    History to calibrate on, in the fitted schema. None uses the fitted history.

    		 None
    method str | None

    "cqr" (default for models with quantiles), "absolute" (default for point-only models) or "signed". See :mod:tabtune.TimeSeries.calibration.

    		 None
    windows int

    Rolling origins per series.

    		 5
    step int | None

    Steps between origins (default prediction_length).

    		 None
    output_format str

    'rich' logs a calibration report, 'json' prints its summary as JSON.

    		 'rich'

    Returns:

    Type Description
    TimeSeriesPipeline

    self.

    Raises:

    Type Description
    ConfigError

    If the task is not forecasting or no quantile levels were requested.
    ValueError

    If there are too few calibration rows for the requested levels.

    		 None

    		 3
    step int | None

    		 None
    output_format str | None

    evaluate(df_actual: pd.DataFrame, *, forecast: ForecastResult | None = None, history: pd.DataFrame | None = None, output_format: str = 'rich') -> dict[str, Any] ¶

    Score forecasts against observed values.

    Compares the forecast with the rows of df_actual whose (item, timestamp) keys fall in the forecast window. By default the forecast is produced here from the fitted history; pass forecast to score one you already have. For sampling models without a seed, a new forecast differs from an earlier one.

    Parameters:

    Name Type Description Default
    df_actual DataFrame

    Observed values over the horizon, in the fitted schema.

    		 required
    forecast ForecastResult | None

    A forecast to score, e.g. the result of :meth:predict.

    		 None
    history DataFrame | None

    History to forecast from instead of the fitted one. Cannot be combined with forecast.

    		 None
    output_format str

    'rich' logs the metrics, 'json' prints them as JSON, as in TabularPipeline.evaluate.

    		 'rich'

    Returns:

    Type Description
    dict[str, Any]

    mae, rmse, mse, smape and mase over every
    dict[str, Any]

    forecast point; with quantiles also mean_pinball_loss,
    dict[str, Any]

    wql and the coverage of the widest central interval. MASE is
    dict[str, Any]

    scaled by each series' seasonal naive error on its history. A
    dict[str, Any]

    multivariate forecast also reports per_target, the same
    dict[str, Any]

    metrics for each target on its own scale, since averaging across
    dict[str, Any]

    targets that are measured in different units says little.

    Raises:

    Type Description
    RuntimeError

    If called before :meth:fit.
    ValueError

    If both forecast and history are given, if timestamps differ in timezone, or if no row of df_actual matches a forecast timestamp.

    save(file_path: str) -> None ¶

    Save the fitted pipeline.

    Pretrained weights are not stored. They reload from checkpoint on first use after :meth:load, which needs network access or a populated Hugging Face cache; for offline use, fit with a local checkpoint directory. Fine-tuned weights (the LoRA adapters for "peft") are stored and re-applied.

    Load a pipeline written by :meth:save.

    Return the constructor arguments, so the pipeline can be rebuilt or cloned.

    clear_cache() -> int ¶

    Drop this pipeline's cached results. Returns the number removed.

    Input and output types¶

    tabtune.TimeSeries.schema.TimeSeriesSchema dataclass ¶

    Column roles of a long-format time series frame.

    Attributes:

    Name Type Description
    target str | Sequence[str]

    Column holding the value to forecast, or a sequence of columns for a multivariate target forecast jointly.
    timestamp str

    Column holding the observation time. Anything :func:pandas.to_datetime accepts.
    item_id str | None

    Column identifying the series in a panel. None treats the whole frame as a single series.
    freq str | None

    Pandas frequency of the series ("D", "h", "MS"...). None infers it per series and requires the inferences to agree.
    past_covariates tuple[str, ...]

    Columns observed alongside the target over the history.
    known_covariates tuple[str, ...]

    Columns also known over the forecast horizon. Their future values are supplied to predict through future_df.

    Covariate columns may be numeric or categorical; a model that does not support covariates, several targets, or categorical covariates rejects the schema when the pipeline is fitted.

    covariate_names: tuple[str, ...] property ¶

    Every covariate column, past-only first then known-future.

    is_multivariate: bool property ¶

    Whether the schema names more than one target.

    columns: tuple[str, ...] property ¶

    The columns this schema reads, in canonical order.

    future_columns: tuple[str, ...] property ¶

    The columns a future_df must carry, in canonical order.

    to_panel(df: pd.DataFrame, *, native_missing: bool = False, future_df: pd.DataFrame | None = None, horizon: int | None = None) -> TimeSeriesPanel ¶

    Validate df against this schema and return the canonical panel.

    The input frames are never modified.

    Parameters:

    Name Type Description Default
    df DataFrame

    Long-format history frame.

    		 required
    native_missing bool

    Whether the model accepts NaN in the target history. When False, missing targets are rejected.

    		 False
    future_df DataFrame | None

    Known-future covariate values covering the horizon, one row per (item, timestamp). Optional: the history is valid without it, and :meth:attach_future can supply it later.

    		 None
    horizon int | None

    Forecast length, needed to check future_df covers exactly the steps that follow each series.

    		 None

    Returns:

    Type Description
    TimeSeriesPanel

    The validated panel, one row per (item, target), items ordered
    TimeSeriesPanel

    by id and each series in time order.

    Raises:

    Type Description
    TypeError

    If df is not a DataFrame.
    ValueError

    On missing columns, a non-numeric target, unparseable timestamps, infinite target values, duplicate (item, timestamp) keys, an irregular or inconsistent frequency, disallowed missing values, a series with no observations, or a future_df that does not line up with the history.

    attach_future(panel: TimeSeriesPanel, future_df: pd.DataFrame, *, horizon: int | None) -> TimeSeriesPanel ¶

    Return panel with known-future covariate values attached.

    future_df must cover exactly the horizon steps after each series' last observation.

    Raises:

    Type Description

    tabtune.TimeSeries.schema.TimeSeriesPanel dataclass ¶

    A validated panel of series, ready for a model adapter.

    One row is one (item, target) pair: a univariate panel has one row per item, a panel with three targets three consecutive rows per item in schema order. An adapter that forecasts variates jointly recovers the grouping from :meth:item_groups.

    Attributes:

    Name Type Description
    item_ids tuple[Hashable, ...]

    One identifier per row. (None,) for a single series given without an item column. Repeated across a multivariate item.
    values tuple[ndarray, ...]

    Per row, the target history as a 1-D float64 array in time order. NaN marks a missing observation; every other value is finite.
    last_timestamps tuple[Timestamp, ...]

    Per row, the timestamp of the final observation; forecasts start one step after it.
    freq str

    Pandas frequency string shared by every series.
    target_names tuple[str, ...]

    Per row, the name of the target column it holds.
    past_covariates tuple[Mapping[str, ndarray], ...]

    Per row, a mapping of covariate name to a 1-D array as long as that row's history. Shared by the rows of one item.
    future_covariates tuple[Mapping[str, ndarray], ...]

    Per row, a mapping of covariate name to a 1-D array as long as the forecast horizon. Shared by the rows of one item. Empty unless the schema names known_covariates.

    max_length: int property ¶

    Length of the longest series history.

    n_targets: int property ¶

    Number of target variates per item.

    covariate_names: tuple[str, ...] property ¶

    Names of the past covariates carried by the panel.

    item_groups() -> tuple[tuple[int, ...], ...] ¶

    Return the row indices of each item, in panel order.

    A univariate panel gives one index per group. An adapter that forecasts an item's variates jointly uses these groups to assemble its inputs.

    tail(n: int) -> TimeSeriesPanel ¶

    Return a copy keeping only the most recent n observations per row.

    last_timestamps is unchanged: truncating the context does not move the forecast origin. Past covariates are cut to the same window; future covariates describe the horizon and are left alone.

    check_observed(*, context: int | None = None) -> None ¶

    Raise if any row has no observed value.

    Run on the window a model actually sees: cutting to the context length can leave an all-missing window.

    Raises:

    Type Description
    ValueError

    Naming the first row with no observed value.

    fingerprint() -> str ¶

    Return a content hash of the panel, used as the forecast cache key.

    Covers everything that changes a forecast input: item ids, target names, values, covariate values, forecast origins and frequency.

    tabtune.TimeSeries.forecast.ForecastResult dataclass ¶

    Point and quantile forecasts for a panel of series.

    The arrays are read-only; use :meth:to_pandas or np.array(result.point) for a writable copy. A row is one (item, target) pair: a univariate forecast has one row per item, a multivariate one consecutive rows per item.

    Attributes:

    Name Type Description
    item_ids tuple[Hashable, ...]

    One identifier per row of the arrays.
    timestamps ndarray

    [row, horizon] forecast timestamps.
    point ndarray

    [row, horizon] point forecast. Which statistic it is (mean or median of the predictive distribution) depends on the model and is recorded in metadata.
    quantiles ndarray | None

    [row, horizon, quantile] forecasts, or None when no quantiles were requested.
    quantile_levels tuple[float, ...]

    The level of each entry on the last axis of quantiles.
    targets tuple[str, ...]

    Name of the forecast target column of each row.
    item_id_column str | None

    Item column name from the schema, or None for a single series.
    timestamp_column str

    Timestamp column name from the schema.
    metadata Mapping[str, Any]

    Provenance: model, checkpoint, device, strategy and whether any training occurred.

    target: str property ¶

    The single forecast target.

    Kept for univariate results. For multivariate result read :attr:targets instead.

    prediction_length: int property ¶

    Forecast horizon in steps.

    to_pandas() -> pd.DataFrame ¶

    Return the forecasts as a long frame, one row per (item, target, timestamp).

    Columns: the item column (panels only), the timestamp column, target, point, then one column per quantile level named by its string value ("0.1", "0.5"...).
