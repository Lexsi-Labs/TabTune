# T0

T0 is The Forecasting Company's open-weights time series foundation model. It is a patch transformer that factorises attention over time and over the variates of a series, in the line of Datadog's Toto and Amazon's Chronos-2. It forecasts an item's targets jointly and conditions on known-future covariates. Quantile levels between the trained ones are interpolated and levels beyond them extrapolated on exponential tails, so any level in (0, 1) is served. TabTune vendors the PyTorch runtime of `tfc-t0` 0.6.0 in `tabtune/models/t0`; the MLX runtime, evaluation and plotting helpers are not vendored.

| | |
|---|---|
| `model_name` | `"T0"` (aliases `"t0-gamma"`, `"TFC-T0"`, `"T0-Forecaster"`) |
| Tasks | forecasting, anomaly detection, imputation, embedding |
| Strategies | `inference`, `finetune`, `peft` |
| Checkpoints | `theforecastingcompany/t0-alpha`, `t0-beta`, `t0-gamma` (default) |
| Multivariate / covariates | yes; known-future numeric, and past-only as extra variates |
| Quantiles | any level in (0, 1) |
| Report | [arXiv:2609.24559](https://arxiv.org/abs/2609.24559) |

## Usage

```python
from tabtune.TimeSeries import TimeSeriesPipeline, TimeSeriesSchema

schema = TimeSeriesSchema(target="load", item_id="zone", known_covariates=["holiday"])
pipe = TimeSeriesPipeline("T0", forecast_params={"prediction_length": 64, "quantile_levels": [0.05, 0.5, 0.95]})
forecast = pipe.fit(history, schema, future_df=future_calendar).predict()
```

## Model parameters (`model_params`)

| Parameter | Default | Description |
|---|---|---|
| `checkpoint` | `theforecastingcompany/t0-gamma` | A Hub repo or a local `save_pretrained` directory. |
| `batch_size` | `64` | Items per forward pass. Items of different lengths are batched with `TimeSeries.batch`, which pads on the left with cells the model does not attend to. |
| `trim_leading_missing` | `True` | Treat missing values before the first observation as padding. |
| `symmetric_averaging` | `True` | Average with the mirrored forecast of the negated series (two passes). |
| `clip_nonnegative` | `True` | Clip at zero when the history is non-negative. |
| `snap_integers` | `True` | Round when the history is integer-valued. |
| `revision`, `local_files_only` | | Hugging Face download options. |

The four adjustments use only each series' own history and together give t0-gamma's published scores, which is why TabTune turns them on; set any of them to `False` for the raw model output. Past-only covariates go in the context as extra variates, as upstream documents: they are attended to and forecast with the targets, and their forecasts are dropped. Known covariates need their history as well as the horizon. Covariates must be numeric. T0 runs in float32.

## Fine-tuning

`finetune` updates every weight and `peft` trains LoRA adapters on `wQKV`, `wO`, `mlp.0` and `mlp.2`, the targets of upstream's LoRA notebook. Training windows are univariate target windows. The loss is the pinball loss over the native quantiles in the model's normalised space: one differentiable forward pass over the scaled rollout window, with the targets moved into the scaler's location and scale frame. Training horizons are clamped to the model's single-pass horizon (1,024 steps).

## Embeddings

One vector per target row: the transformer outputs averaged over the observed context patches, `embed_dim` wide.
